# 版本

最新的版本在最前面；每一版的完整记录见仓库里的 CHANGELOG.md。

## 2.3.2（2026-11-04） {#v2-3-2}

- 也叫：往回弹、回弹、滚动跳、默认打开的卡、Gemini 原生、503、MOSS 朗读、安卓导出对话

- 新增：供应商的接口类型多了「Gemini 原生（generateContent）」，「Gemini API」模板默认用它，以前建的在编辑里改接口类型就行。
- 新增：朗读来源加了 MOSS（MOSI 开放平台的 moss-tts，国内直连）。
- 新增：安卓应用能导出对话包（⇩）和角色卡 PNG，文件存进手机的「下载」文件夹。
- 改进：画图方式「OpenAI 兼容图片接口」下面列出了 MOSS、OpenRouter 等服务，标着国内直连或需科学上网。
- 修复：切换对话、写完新回合后正文停在最新几轮之前（2.3.1 带进来的）；划动换版本、改消息、隐藏回合时也不再跳开。
- 修复：打开应用时进的卡不对。现在打开最近聊过的对话，一段对话都没有时打开侧栏最上面的卡。
- 修复：模型繁忙、限流、额度用完被说成连不上或服务出错；现在各说各的，并说明不是你的网络问题。
- 修复：视觉小说模式里看不出回复配图在不在画；现在左上角写着进度和秒数，可以取消，没画成可以重试。

## 2.3.1（2026-11-03） {#v2-3-1}

- 也叫：卡顿、长对话卡、刻度条折叠、STscript、斜杠命令、手机删除按钮

- 新增：卡片界面能用的 SillyTavern 命令多了很多（/setvar、/if、/while、/sys、/cut、/gen、/buttons 等，带管道和闭包）；这里没有的命令跳过那一步，其余照常执行，并提示一次。
- 改进：楼层多的对话不卡了：看不见的消息不参与排版，两三百轮时一边生成一边重排的开销几乎为零，打开长对话也快了好几倍。
- 改进：长对话的刻度条只铺开正在看的十轮左右，其余收进两头的细纹带，翻动和拖动时跟着展开。
- 修复：手机上对话列表的删除按钮看不见、角色卡的 ⋯ 太淡。
- 修复：Base URL 中间多了空格时连不上（报 API Key 无效或拿不到模型列表）。
- 修复：开局页用 /sys 和 /trigger 开始剧情的卡报「界面里的命令 /sys 在这里不支持」；卡片界面存变量后整个对话闪一下、界面从头开始。

- 新增：模型供应商：OpenAI 兼容、OpenAI Responses、Anthropic 三种接口和常见厂商模板，每个对话可以单独选模型。
- 新增：导入 PNG / JSON 角色卡、SillyTavern 世界书和预设；MVU 变量、EJS、正则、卡片自带的 HTML 界面、酒馆助手兼容。
- 新增：对话：缓存友好、后台生成、重新生成、分支、回滚、压缩上下文成剧情存档、对话包（.tavernchat）。
- 新增：配图（OpenAI 兼容图片接口、ComfyUI、NovelAI，角色名册）、朗读（浏览器语音、外部语音服务）、用量面板。
