        挂上的世界书和卡里自带的一起生效：常驻条目进固定前缀，关键词条目按最近的对话触发。

        「跟随系统代理」读 Windows 的代理设置（Clash、v2rayN 开了「系统代理」时就是它），每分钟更新一次。只支持 HTTP 代理，SOCKS 不行。供应商设成「直连」的（DeepSeek 等国内服务）不走代理。保存后立刻生效。

        改完要重启服务。不要把端口映射到公网：拿到链接的人能用你的模型额度。出门时在电脑和手机都装 Tailscale，用这里的 Tailscale 地址打开。手机打不开时，在 Windows 防火墙里允许 Node.js 入站。

        自动检查更新的开关在「更新」里。字体的改动下次打开时生效。

        菜单、按钮和提示用的语言，保存后页面刷新一次。故事用什么语言写，在「文风与字数」的「写作语言」里改。
